# Deploy Gallery บน Vercel

ตั้งค่า Vercel project ดังนี้:

```text
Root Directory: gallery
Environment Variable: MOMENTLINK_API_URL=https://your-render-service.onrender.com
Production Branch: main
```

ลิงก์สาธารณะของงานใช้รูปแบบ:

```text
https://your-vercel-project.vercel.app/?event=PUBLIC_ID
```

อย่าใช้ `localhost` หรือ IP LAN ใน QR สำหรับผู้ใช้นอกเครือข่ายโรงเรียน
